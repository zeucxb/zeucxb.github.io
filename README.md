# Eliseu Codinhoto

## Como editar e publicar

1. Edite o site no Cursor. O arquivo principal é `index.html`.
2. Abra um pull request.
3. Os checks do PR rodam sozinhos: HTML, links e arquivos internos, e ausência de overflow horizontal em 320, 375 e 1280 px nos quatro idiomas (pt, en, es, it). Se algo quebrar, o PR falha.
4. Merge na `master`: o GitHub Pages publica o site em cerca de 1–2 minutos.
5. Os PDFs do currículo (`/resume.pdf`, `/resume-pt.pdf`, `/resume-es.pdf`, `/resume-it.pdf`) são gerados de novo automaticamente a partir da página do currículo.
